# Core Banking Interno

Core de créditos y cuentas — sistema web, API-first, con múltiples tipos de crédito.

## Estructura del repositorio
- `backend/` — API en ASP.NET Core
- `frontend/` — aplicación web en React
- `database/` — scripts de creación y migración de base de datos (SQL Server)
- `docs/` — documentación funcional y técnica del sistema
